Customer Shopping Behavior Analysis

This end-to-end data analytics project analyzes the shopping patterns of nearly 4,000 customers to uncover how different demographic factors, product categories, and shipping choices influence spending behavior.

Using Python, SQL, and Power BI, the project moves from raw data → cleaned dataset → statistical insights → visual dashboard.
It highlights key business metrics such as average purchase amount, customer segmentation, revenue breakdown, and category performance, helping businesses make informed decisions about marketing, inventory, and customer engagement.
